Control flow statements

Decision-making statements

| Control flow statement |
| --- |
| if-then      |
| if-then-else |
| switch       |

A switch works with the byte, short, int and char primitive data types. It also works with enumerated types, the String class, and a few special classes that wrap certain primitive types: Byte, Short, Integer and Character.

Looping statements

| Control flow statement |
| --- |
| for      |
| while    |
| do-while |

The difference between do-while and while is that do-while evaluates its expression at the bottom of the loop instead of the top. Therefore, the statements within the do block are always executed at least once.

Branching statements

| Control flow statement |
| --- |
| break    |
| continue |
| return   |

An unlabeled break statement terminates the innermost switch, for, while, or do-while statement, but a labeled break terminates an outer statement.

An unlabeled continue statement skips to the end of the innermost loop's body and evaluates the boolean expression that controls the loop. A labeled continue statement skips the current iteration of an outer loop marked with the given label.
